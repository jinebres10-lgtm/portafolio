Aplicaciones a la medida

Plataforma interna integral · Node.js + React · IA generativa

Suite de aplicaciones a la medida construida de cero (backend, frontend y despliegue) para digitalizar la operación completa de una consultora: gestión interna, un asistente de IA que resume reuniones y extrae tareas accionables a partir de transcripciones, y un conjunto de módulos ambientales para captura, cálculo y reportería de datos de sostenibilidad de clientes externos.

Gestión interna: RR.HH. (solicitudes, empleados), inventario con CRUD completo, gestión de proveedores, gestión de proyectos, procesos administrativos, cultura organizacional y reconocimiento entre equipos.

Innovación y monitoreo: módulo de innovación para captura y seguimiento de iniciativas internas, monitoreos ambientales periódicos y un módulo de estrés climático para evaluar exposición y riesgo físico ante variables climáticas.

Datos ambientales multi-empresa: captura y análisis de residuos, energía, agua, emisiones, producción y cumplimiento normativo por empresa, con dashboard, gráficas interactivas (tendencias, comparativas, distribución) y exportes de reportes; modelo de roles (superadmin / admin / usuario) con acceso segmentado por organización para clientes externos e internos.

Huella de carbono: motor de cálculo propio alineado a GHG Protocol e ISO 14064-1, catálogo de más de 350 factores de emisión editable e importable/exportable vía Excel, manejo de incertidumbre estadística y métodos especiales (mezclas de biocombustible, refrigerantes, biomasa).

Diagnóstico ESG: cuestionario tipo wizard con scoring ponderado por dimensión, identificación de brechas, plan de trabajo sugerido y generación de reporte en PDF, con acceso público sin necesidad de cuenta.

Agente de causación contable (DIAN)

Automatización · Python · Microsoft Graph

Agente que automatiza la clasificación contable y causación de facturas electrónicas recibidas, integrando reglas de negocio por proveedor, cálculo de retenciones, y sincronización con archivos Excel vivos en SharePoint sin bloquear su edición manual.

Corre de forma programada (GitHub Actions), con más de 80 pruebas unitarias y manejo cuidadoso de condiciones de carrera al escribir sobre archivos compartidos en uso simultáneo.

Python Microsoft Graph API GitHub Actions SharePoint

Clasificación de coberturas terrestres con Deep Learning

Evaluación técnica · visión por computador · SIG

Diseño de arquitectura para una herramienta de deep learning que asiste la fotointerpretación de coberturas de la tierra (metodología CORINE Land Cover, adaptación IDEAM) a partir de imágenes satelitales, integrada como capa editable dentro de un flujo de trabajo en ArcGIS.

Incluyó análisis de viabilidad técnica, estrategia de despliegue por fases para mitigar el riesgo de un dataset de entrenamiento modesto, y documentación formal de la evaluación.
